# AGMAD Silent Cutter 1.5.1

**الإصدار المستقر 1.5.1 منشور بموافقة صاحب المشروع.** أكد صاحب المشروع نجاح اختباري Mac وWindows.

- مقياس القص −5…+5، وضع مخصص، أو «بدون قص» للاحتفاظ بفترات الصمت.
- تنظيف الصوت مستقل: بدون تنظيف، إزالة الضوضاء، أو إزالة الموسيقى الاختيارية.
- شعار PNG قابل للسحب مع التحكم في الحجم والعتامة.
- فيديوهات MP4 مباشرة في مجلد واحد، والسجلات داخل بيانات التطبيق.
- الاسم الأصلي أو التاريخ أو التاريخ والاسم أو رقم تسلسلي، مع بادئة اختيارية وبدون استبدال الملفات.

[التثبيت والتعليمات بالعربية](docs/WINDOWS_1.5.1_TEST.ar.md) · [المشروع بالإنجليزية](README.md). ابدأ باختبار 30 ثانية وراجع الكلام وتزامن الصوت. تتطلب العلامة المائية مرحلة ترميز إضافية. لا توجد إضافة لتغيير السرعة أو اختيار Shorts في هذا الإصدار.

الحزم المختبرة تحتفظ بتسميات الاختبار الأصلية داخلها، ولا تعني إعادة تسمية ملفات التنزيل إعادة بناء البرنامج. توقيع Mac محلي وغير موثق من Apple؛ حزمة Windows دون توقيع ناشر. تبقى تراخيص الجهات الخارجية مستقلة.
