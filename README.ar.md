# AGMAD Silent Cutter

برنامج محلي لقص فترات الصمت من الفيديو على Mac وWindows، مع تنظيف اختياري للصوت ومقارنة الأصل بالنتيجة.

**الإصدار المرشح 1.4.0 — 20 أكتوبر 2026.** أكد صاحب المشروع عمل نسختي 1.3 على الجهازين. يضيف هذا التحديث تنسيقًا متوافقًا مع هوية أجمد وأيقونات وتوثيقًا جاهزًا للمشاركة، دون تغيير محرك المعالجة. أصبح [الإصدار التجريبي العام متاحًا](https://github.com/agmadxnet/agmad-silent-cutter/releases/tag/v1.4.0)؛ تفعيل صفحة الموقع خطوة منفصلة.

- [دليل Windows بالعربية](docs/WINDOWS.ar.md)
- [دليل Mac بالإنجليزية](docs/MAC.md)
- [المشروع بالإنجليزية](README.md)

اختر الفيديو ومجلد النتائج، وابدأ بالمستوى 0 واختبار 30 ثانية. التحرك نحو −5 يحافظ على وقفات أكثر؛ التحرك نحو +5 يزيد قوة القص. المستويات الموجبة تطابق المستويات الخمسة السابقة. الصفر لا يعني إيقاف القص.

يتيح الوضع المخصص ضبط عتبة الصوت وهامش الكلام وأقل صمت ضمن حدود محددة. اختر بدون تنظيف، إزالة الضوضاء، أو إزالة الموسيقى الاختيارية. لا تُعدل الملفات الأصلية. راجع الكلام والمقارنة وتزامن الشفاه قبل النشر.

المعالجة محلية؛ يحتاج تثبيت الأدوات والنماذج للمرة الأولى إلى الإنترنت. إزالة الموسيقى أثقل من القص العادي، وقد تترك آثارًا مسموعة. لا توجد ترجمة أو طابور ملفات في هذا الإصدار.
