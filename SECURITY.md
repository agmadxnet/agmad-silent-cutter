# Security and sensitive reports

This desktop app invokes local media tools. Keep originals backed up and process files from sources you trust. Dependencies retain their own update and security policies; automatic updating is not implemented.

Do not place credentials, private media or unredacted logs in a public issue. For a suspected vulnerability, use GitHub's private vulnerability reporting if enabled for the published repository. No private support address or response deadline is currently promised. If private reporting is unavailable, ask for a private reporting channel without disclosing exploit details publicly.

The release is unsigned on Windows and ad-hoc signed on Mac. This repository does not claim notarization, a security audit, sandbox isolation or certified media handling.
