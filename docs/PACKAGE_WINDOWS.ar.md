# AGMAD Silent Cutter — التثبيت والاستخدام على Windows

## التثبيت أو التحديث

تحتاج إلى Windows بمعالج Intel أو AMD بنظام 64-bit. أغلق النسخة القديمة، وفك ضغط ZIP بالكامل في مجلد محلي، ثم افتح **Install.cmd**. لا تشغّل البرنامج من داخل ZIP. افتح اختصار **Agmad Silent Cutter** بعد التثبيت.

تتضمن الحزمة Python وQt؛ لا تحتاج إلى تثبيت Python يدويًا. تبقى الإعدادات والأدوات والنماذج والنتائج السابقة محفوظة. الحزمة غير موقعة باسم ناشر Windows؛ راجع مصدر التنزيل ولا تعطّل حماية النظام عمومًا.

اضغط **تثبيت أدوات المعالجة** عند الإعداد الأول وانتظر اكتمال التنزيل. تحتاج الإنترنت لتنزيل الأدوات والنماذج؛ المعالجة اليومية محلية. تنظيف الموسيقى اختياري وأثقل، وله إعداد إضافي. أعد استخدام الأدوات المثبتة إذا كانت تعمل.

## الاستخدام

1. اختر فيديو ومكان حفظ النتائج.
2. اختر مقياس القص −5 إلى +5، أو القيم المخصصة، أو إيقاف القص. المستوى 0 يقص الوقفات؛ إيقاف القص يحافظ عليها.
3. اختر تنظيف الصوت بصورة مستقلة: بدون تنظيف، إزالة الضوضاء، أو إزالة الموسيقى.
4. اختياريًا اختر علامة مائية PNG واضبط مكانها وحجمها وشفافيتها.
5. اختر أسلوب اسم الملف والبادئة الاختيارية.
6. اختبر 30 ثانية وراجع الكلام وتزامن الشفاه والمقارنة قبل معالجة الفيديو كاملًا.

تُحفظ ملفات MP4 المكتملة مباشرة في المجلد المختار. لا تتغير الملفات الأصلية ولا يُكتب فوق النتائج الموجودة. تبقى السجلات والتقارير والذاكرة المؤقتة في مساحة التطبيق، عادة تحت `%LOCALAPPDATA%\Agmad Silent Cutter`. تثبيت البرنامج تحت `%LOCALAPPDATA%\Programs\Agmad Silent Cutter`.

إيقاف القص ما زال يرمّز H.264/AAC. العلامة المائية تضيف مرحلة ترميز. قد يترك تنظيف الصوت آثارًا مسموعة؛ راجع النتيجة. لا يوجد طابور ملفات أو تصدير بسرعة تشغيل مختلفة أو قص رأسي.
