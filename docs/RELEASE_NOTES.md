# AGMAD Silent Cutter 1.4.0 — prepared release notes

A coordinated AGMAD look for the local Mac and Windows silence cutter, with matching waveform icons, English/Arabic documentation and a clearer route from installation to before/after review.

The working editing behaviour stays the same: unified −5…+5 scale, guided Custom values, optional Noise/Music cleanup, short excerpt tests and linked playback. Existing settings, engines, models and outputs are reused; originals remain untouched.

Mac: Apple Silicon, macOS 14+, initial Homebrew tools setup. Windows: Intel/AMD 64-bit, bundled Python/Qt, Arabic interface and instructions. Optional Music setup needs more download/storage and memory than ordinary cutting.

Installation: quit the old app; replace the Mac app in Applications or extract the Windows ZIP and run Install.cmd. Review a 30-second clip before processing a lecture.

This candidate is ad-hoc signed on Mac and not publisher-signed on Windows. The owner reports both 1.3 platforms working; 1.4.0 native Mac and cross-platform render checks passed. Fresh Windows visual confirmation and broader device testing are still needed. See the validation guide and SHA256SUMS shipped with the release assets.
