Before you download.

Will my video leave my computer?

The desktop processing pipeline does not upload media. Explicit setup downloads third-party tools, packages and optional models. No app telemetry or account system is implemented.

Is voice isolation always needed?

No. Use Off for clean recordings and Noise for steady background sound. Music separation is optional, heavier and can leave artifacts. Severe wind distortion may not be recoverable.

What has been tested?

The owner reports Mac and Windows 1.3 working well. The styled 1.4.0 candidate is checked through native Mac builds and cross-platform GUI/render tests; native Windows visual confirmation and broad device coverage remain separate checks.

What should I know about installation?

Mac requires Apple Silicon/macOS 14+ and Homebrew for the initial tools. Windows includes Python/Qt. This candidate is ad-hoc signed on Mac and has no Windows publisher signature. Follow the specific installation guide; do not disable system protection globally.

Installation and troubleshooting guides are included in each package.
