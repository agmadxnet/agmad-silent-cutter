# Visual identity

Observed live reference: https://agmad.net/ on 20 October 2026. Near-black #060708, primary text #F2F3F6, secondary #AFB6C5, muted #7D8596 and ice-blue #C6D4FF. Native system type; thin product heading, quiet labels, rounded controls and clear borders.

The waveform/pause icon is original vector/code artwork created for this release. SVG source and build script are included under the project MIT license. PNG/ICO/ICNS are generated with scripts/make_icons.py (Pillow, plus iconutil on Mac). No site sculpture, generated hero, third-party photo, or existing site logo asset is redistributed. The AGMAD name identifies the project; trademark rights are not granted by the source license.

App styling is intentionally restrained so the controls and before/after footage remain the focus. No video effects, web renderer, remote font or extra runtime dependency was added for styling.
